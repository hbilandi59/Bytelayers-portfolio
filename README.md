## Project Overview

This repository contains the **portfolio website** for **Bytelayers**, built using the latest web technologies. The website is designed to highlight our core services, showcase past projects, and provide potential clients with a comprehensive overview of what we offer.

### Technologies Used:

- **React**: A popular JavaScript library for building user interfaces.
- **TypeScript**: A superset of JavaScript that provides static typing, making the code more predictable and easier to maintain.
- **Vite**: A modern, fast, and optimized build tool for front-end development.
- **Tailwind CSS**: A utility-first CSS framework that allows for fast styling and easy customizations.

### Features:

- Responsive, mobile-friendly design
- Dynamic portfolio sections showcasing our services and projects
- Contact form integration
- Interactive elements powered by React and TypeScript
- SEO-friendly with proper metadata and keywords for search engines

## How to Run Locally

To run this project locally, follow the steps below:

### 1. Clone the repository:

```bash
git clone https://github.com/your_username/Bytelayers-portfolio.git
```

### 2. Navigate to the Ptoject Directory:

```bash
cd Bytelayers-portfolio
```

### 3. Install dependencies:

```bash
npm install
```

### 4. Start the development server:

```bash
npm run dev
```

### The application will be running on http://localhost:3000.
